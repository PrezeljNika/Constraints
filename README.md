## Opis projekta
Aplikacija HelloConstraint je preprosta interaktivna Android aplikacija, izdelana v programu Android Studio. Namen naloge je spoznati uporabo postavitve ConstraintLayout, dodajanje gumbov, obdelavo klikov in spreminjanje lastnosti elementov uporabniškega vmesnika.

## Funkcionalnosti
**TOAST:** Ob kliku prikaže kratko obvestilo.
**COUNT:** Poveča števec za eno vrednost.
**ZERO:** Ponastavi števec na 0.
Gumb COUNT spreminja barvo glede na sodo ali liho vrednost števca.
Gumb ZERO spremeni barvo, ko je števec aktiven, in se ob ponastavitvi vrne na sivo barvo.

## Uporabljene tehnologije
Java – programska logika in obdelava dogodkov.
XML – oblikovanje uporabniškega vmesnika.
ConstraintLayout – razporejanje elementov in določanje omejitev.
